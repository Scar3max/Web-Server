Under The Hood

This server rejects bloated modern frameworks in favor of raw POSIX system calls. It leverages Linux epoll for O(1) I/O multiplexing, ensuring that thousands of concurrent connections can be handled without blocking the main event loop.

Incoming requests are parsed and handed off to a thread-safe Task Queue. A dynamic pool of worker threads consumes these tasks asynchronously. The result is a highly scalable, Nginx-like architecture built entirely from first principles.
